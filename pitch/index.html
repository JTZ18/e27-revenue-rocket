The problem

The current system is lossy.

A 3-person team answers dozens of enquiries a week using a hand-maintained FAQ, two rate cards, and a "New Questions Log" they update by hand.

What gets answered

28 FAQs · 2 rate cards · 1 product reference · 1 SOP. Everything else is goodwill.

What gets lost

BPA-free strap demand. Vegan-material requests. MRI safety. Carbon-neutral shipping. These show up in inboxes and disappear.

The knowledge base grows by goodwill, not by process.

Boldr Intel
Frontier-tech bet #1

A Karpathy-style LLM wiki — not embeddings RAG.

At MVP scale the wiki IS the retrieval system. The agent reads kb/index.md, drills into files, and cites the paths it read. Markdown in Git is the entire stack.

Why this beats a vector DB at our scale

  • Auditable — "I read kb/faqs/bpa-straps.md" beats a cosine score.
  • Deterministic — same input, same file-read path. No embedding drift.
  • Zero infra — no index pipeline, no re-embed cost, no vector DB.
  • Self-documenting — the file tree IS the taxonomy.

The frontmatter contract

--- slug: bpa-free-straps domain: spec themes: [materials_safety, sustainability] last_verified: 2026-05-16 status: active --- Yes. All Boldr FKM rubber and silicone straps are 100% BPA-free.

Judging criterion · Workflow logic

Structured output as the safety gate.

Every traversal call returns the same shape. can_answer_fully decides which branch runs. There is no path to a fabricated answer.

// TraversalResult — the contract between the agent and the rest of the system { "can_answer_fully": true, "answer_draft": "Yes. All Boldr FKM rubber straps are 100% BPA-free…", "cited_paths": ["kb/faqs/bpa-straps.md", "kb/products/expedition.md"], "missing_info": [], "themes_detected": ["materials_safety", "sustainability"], "persona_hints": ["health_conscious"], "escalation_required": false }

If can_answer_fully = false, the pipeline creates a gap. Never a draft.

Boldr Intel
Judging criterion · Proof of execution

Three independent quality signals.

Ground truth

CSV ships with held-out labels (question_type, buyer_persona, answered_by_kb, requires_escalation). Agent never sees them. Per-class precision/recall/F1 reported.

Hand rating

20 drafts hand-rated on a 5-dimension rubric: grounded, brand_voice, completeness, no_hallucination, tone_fit. Named reviewer credited.

LLM-as-judge

50 more drafts judged by Kimi against the same published rubric. Cohen's kappa + per-dimension MAE on the 20 overlap.

If the judge disagrees with humans, the kappa tells you. Nothing is trust-me.
